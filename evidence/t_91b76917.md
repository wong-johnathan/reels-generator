## Limitations

- No live Gemini request: tests never call a paid provider. The REST shape is asserted against an
  injected fetch; the real provider path is unexercised here.
- Real-provider qualification cannot auto-pass: with no automatic identity verifier the runner
  records `passed=false, requires_human_review=true` and only an explicit operator verdict records
  a pass. Qualification of the real adapter is billable (3 images).
- The shared token bucket has no abortable wait; a queued caller cannot be cancelled by the 60 s
  request timeout (the timeout starts after quota is granted).
- The rate limiter is in-process; the Redis-mirrored bucket of TECH_DESIGN §5.7 is B-08's.
- Retry/backoff execution is B-08; this task classifies failures only.
- DB-backed qualification test needs `TEST_DATABASE_URL` (skips loudly without it).
