## What this adds

- `GET /videos/:id` and `GET /videos/:id/:tab` — the seven-tab workspace shell
  (`src/web/render/workspace.ts`, `src/web/app.ts`), server-rendered, with the
  stage rail, the header chip, the stale ribbon, the per-tab stage summary and
  the pins/scenes footer.
- The stage rail (UC-03) — eleven nodes, code + state word + pin + 2 px
  determinate progress, FA/EX gate tags, `aria-current="step"`, one tab stop,
  arrow/Home/End roving.
- The state chip (UC-04) — eight states at 20/24/28 px, structural channels
  (dashed+hatch stale, 4 px left edge failed, 3 px double blocked, 3 px right
  edge awaiting approval, strike-through cancelled) with the word always present.
- The stale ribbon (UC-05) — first run of three or more consecutive stale stages,
  hidden server-side and revealed by the enhancer.
- `GET /` — S-02 attention inbox, including the batchless Milestone A card,
  a link straight to each item's gating tab, the empty/loading/error states and
  the exact first-run copy.
- `src/web/workspace/events.ts` — the SSE reducer behind IP-05/AX-27, parsing
  exactly the contract's five `SseEventSchema` variants and failing closed.
- `src/web/client/workspace.ts` — progressive enhancement: live rail/chip/ribbon
  updates, overview row removal, count updates, freshness stamp, polite
  announcements, keyboard model.
- `src/web/styles/workspace.css` (+ regenerated `embedded.ts`).
