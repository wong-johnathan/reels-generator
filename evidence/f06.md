## Browser verification (real Chromium)

Pages were rendered from the live renderers with the contract fixtures, written
as self-contained HTML (embedded stylesheet, SVG stand-ins for `/asset/*` thumbs
because the browser sandbox has no route to the app), and loaded over `file://`.
The shipped enhancer was executed in the page as ES modules built from
`dist/src/web/**` (blob URLs), so the keyboard behaviour below is the real
client module, not a stand-in.

1280 × 1000, checkpoint open:

- 17 tiles, 6 columns, tile width 168 px, thumb aspect ratio 1.778 (9:16).
- Header: `Scenes` + `Awaiting approval` chip + `3 of 17 generated · 14 not started`.
- Checkpoint banner `rgb(48, 38, 20)` (warning surface), CTA `Release remaining 14 · 14 image calls` (44 px, enabled, wired).
- Tiles 1–3 `DONE` with `v3` pin; tiles 4–17 `NOT RUN` with the empty-thumb glyph.
- No horizontal document scroll (scrollWidth 1265 ≤ 1280).

390 × 844, same page:

- 2 columns, tile width 175 px, thumb ratio 1.778, selection bar becomes static (142 px), release control 44 px.
- `htmlScrollWidth` 390 and `scrollX` 0 after scrolling right: no horizontal page scroll.

Keyboard, real enhancer, 1280:

- Exactly one roving tab stop (`[data-scene-tile][tabindex="0"]` = 1), others `-1`.
- `j` / `ArrowDown` move the selection and focus (`S02`, `S03`, `S04`), the 2 px selection outline follows, `Escape` clears.
- Live region after selection: `Scene 4 of 17, S04, not run, 4.4 seconds`.
- Selection bar: `selected: S04 · replace 1 image call · reorder 0 calls`, replace link `/videos/…/scenes/dddddddd-…-000000000004#replace-image`.
- Accessible names: `Scene 3 of 17, S03, done, 4.4 second narration, pin v3`; thumbs carry alt text (`Scene 1: the protagonist meets the idea`).

## Notes / follow-ups

- The workspace tab strip now carries seven tabs; at 390 px it scrolls inside
  itself (`contain: layout`) so the document never gains a horizontal scrollbar.
  This is the only shell CSS touched by this card.
- Contract gaps surfaced in S-13 and stated in the UI: provider request id and
  rights/licence are not returned by `scenes.get` (F-06-2), and prior attempts are
  not exposed (F-06-3); the current asset plus the stage attempt count are shown
  instead of inventing data.
