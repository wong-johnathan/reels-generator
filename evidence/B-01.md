### Local execution of the release-manifest step script

The `run:` block of the `release-manifest` step was extracted from the committed workflow and
executed locally under bash with synthetic digest files (GitHub substitutes `${{ }}` before the
shell runs, so `${{ env.RELEASE_TAG }}` was replaced with `v9.9.9-test`):

    [PASS] prefixed digests are normalised to bare 64-hex: exit=0
      images.env: RELEASE_TAG=v9.9.9-test | WEB_DIGEST=<64 hex> | WORKER_DIGEST=<64 hex> | OPS_DIGEST=<64 hex>
    [PASS] malformed digest fails the release job: exit=1
      ::error::the build job returned an unexpected digest: sha256:deadbeef

This is what closed the one real gap found in this task: before the fix, `images.env` carried
`sha256:<hex>` and `compose.yaml` prepended another `sha256:`, so every pull would have asked for
`@sha256:sha256:<hex>`.

## Limitations (not claimed as passing)

1. **No Docker daemon / no Compose plugin on this host.** `docker --version` → `26.1.5+dfsg1`,
   but `docker info --format '{{.ServerVersion}}'` → "Cannot connect to the Docker daemon at
   unix:///var/run/docker.sock"; `docker compose config -q` → "docker: 'compose' is not a docker
   command"; `docker-compose` → command not found. So `compose up`, `compose config` and any
   image build/pull were **not** executed. The compose contract is verified by parsing
   `compose.yaml` in `tests/compose.test.ts`, not by starting containers.
2. **No GitHub remote / no GHCR credentials.** `git remote -v` is empty, so `build.yml` has never
   run in Actions and no image has been published to GHCR from this host. The workflow is verified
   statically (YAML parsed and asserted by tests) plus the locally executed release-manifest script.
   A real `workflow_dispatch` on a GitHub mirror is still required to close the runtime half of the
   Signal line.
3. **`MINIO_IMAGE` is operator-supplied.** `minio/minio` is no longer served by Docker Hub and
   quay.io requires auth, so `compose.yaml` guards it with `:?` and `docs/DEPLOYMENT.md` §2.5 tells
   the operator to pin tag+digest. No default digest is invented. This is a deliberate, documented
   deviation, not an oversight.
4. **`web`/`workers` do not `depends_on: migrate`.** Compose cannot gate a default-profile service
   on a profile-gated one-shot; `deploy/up.sh` runs migrate first. Documented in `compose.yaml` and
   `docs/DEPLOYMENT.md`.
