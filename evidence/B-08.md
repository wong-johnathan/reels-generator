# B-08 — Attempt-row-before-call + retry/backoff + queue topology + reconciler

US-013 (attempt ledger, unknown charge), US-031 (retry scope storage half).
Branch `feat/t_b3d9c9d4`; implementation commit `1d72a16`; full acceptance mapping,
commands and limitations in `evidence/t_b3d9c9d4.md`.

## What this task owns

- `src/workers/attempt.ts` — one attempt = one committed `job_attempt` + `generation_run`
  (`openAttempt`, B-02's guard), executed through `executePersisted`; outcome recording;
  transient/non-retryable classification across all four adapter error vocabularies; the
  1 s / 4 s / 16 s ladder with a three-attempt ceiling; `unknown` charge marking whenever a
  call may have billed; the "a pending run is never reissued" guard (a live lease is refused
  without touching the winner's rows; a stale one is marked `unknown charge`).
- `src/workers/queues.ts` — BullMQ topology (`content` 4, `render` 1, `export` 1, `misc` 2),
  stage→queue routing (`FA` refuses), priorities (resume/manual retry < new work < reframe),
  attempt-aligned retry budget, custom backoff type, deterministic colon-free job ids,
  `UnrecoverableError` mapping for non-retryable failures.
- `src/workers/reconciler.ts` — startup scan of stale `queued`/`running` jobs by lease;
  pending run ⇒ unknown charge + job failed, never reissued; no in-flight run ⇒ resume at the
  next attempt, retry scope stored before enqueue; attempt ceiling enforced.
- Repository additions needed by the above: `src/db/repositories/jobs.ts` (new) plus appended
  helpers on B-02's `job-attempts.ts`, `generation-runs.ts`, `types.ts`.
