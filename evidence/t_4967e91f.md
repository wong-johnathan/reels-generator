## Limitations and follow-ups (not silently chosen)

- L1 - No live provider call was made. Tests may not call a paid provider, and qualification search/fetch is billable; spending requires explicit owner authorization. The qualification mechanism is proven end-to-end against the _real_ DeepSeek adapter with recorded API-shaped responses (`research-deepseek.test.ts`, "research qualification through the real adapter") and against a real `provider_qualification` table with the deterministic fake. The live run is a single call of `qualifyResearch(createResearchAdapterFromEnv(env), { run, db })` by the operator/pipeline before any billable stage.
- L2 - The Gemini grounding mapping (groundingChunks + groundingSupports confidence, normalised to 0-3 by confidence x 3) and the "no fetch" boundary are implemented from the documented response shape but were not exercised against the live Gemini API. The fallback is not the default and needs its own key + config.
- L3 - `src/adapters/qualification.ts` and `src/adapters/rate-limit.ts` are shared adapter infrastructure that B-04/B-06/B-07 also need. If those branches bring their own copies, INT-01 must keep exactly one (flagged as a hotspot in the completion metadata).
- L4 - `RESEARCH_PROVIDER` and `GEMINI_GROUNDING_MODEL` are new env keys, not in TECH_DESIGN 9.6's list. TECH_DESIGN 5.2 requires the fallback to be selected by configuration, not code, so the keys are additive; `.env.example` lists names only and the validator rejects any value other than deepseek/gemini.
- L5 - The Redis-mirrored rate-limit bucket of TECH_DESIGN 5.7 ("a worker restart does not reset the window") is worker wiring owned by B-08; this adapter ships the in-process bucket only.
- L6 - The adapter takes a structural `{ id, stage }` run reference so it cannot be called with a request alone; the worker must pass B-02's branded `PersistedGenerationRun` obtained from `openAttempt()`, and B-08's dispatch must call `search`/`fetch` (research has two operations, unlike the single-`execute` adapters B-02 defined).
- L7 - The DB suite ran against the vendor-embedded PostgreSQL 16.14 scratch cluster (same limitation B-02 recorded), not the compose image, and no Docker daemon is available on this host.

No secret appears in this file; only key names.
